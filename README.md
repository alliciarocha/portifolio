## 🛠️ Tecnologias Utilizadas
- **Core**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Estilização**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animações**: [Motion](https://motion.dev/)
- **Design original**: [Figma](https://www.figma.com/design/GdX08U9MP1wUhgiCqokEZG/Resume-Site-with-Animated-Water-Background--Community---c%C3%B3pia-)

## 🚀 Como Executar o Projeto Localmente

1. **Instale as dependências:**
   ```bash
   npm install
   ```

2. **Execute o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
   *O site estará disponível no endereço `http://localhost:5173/`.*

3. **Gerar build de produção:**
   ```bash
   npm run build
   ```

4. **Visualizar localmente a versão compilada de produção:**
   ```bash
   npm run preview
   ```

## 📦 Deploy Automatizado (CI/CD)
O deploy deste site é realizado de forma totalmente automatizada através do **GitHub Actions**. Qualquer alteração enviada (`git push`) para a branch `main` disparará o build e publicação dos arquivos no GitHub Pages.
